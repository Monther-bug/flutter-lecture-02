Step 0 · The toolkit

What we're installing

Four tools. Each one has one job.

01

Git

Downloads Flutter for you and keeps track of your code's history.

git-scm.com
02

VS Code + Flutter extension

Where you write code. The extension adds Flutter commands and buttons.

code.visualstudio.com
03

Flutter SDK

Flutter itself: the flutter command, Dart and all the widgets.

SDK = Software Development Kit docs.flutter.dev (one zip file)
04

Android Studio

Brings the Android SDK and the emulator: a virtual phone on your laptop.

developer.android.com/studio

Before you start

Windows 10/11 (64-bit) or macOS
8 GB RAM (16 GB is better)
About 15 GB free disk space
Good internet: several GB to download
Admin access on your laptop

An analogy: Git is the delivery truck that brings Flutter. VS Code is your workbench. The Flutter SDK is the toolbox. Android Studio is the phone lab.

Check disk space now. Anyone with less than about 15 GB free should clean up first. The downloads are big, so start Android Studio downloading on good Wi-Fi.

The most common mistake: Windows suggests a long folder like Downloads\flutter_windows_3.47.6-stable. Delete all of it and type C:\develop. Windows creates the folder.

Why C:\develop? It has no spaces and no Arabic letters, and doesn't need admin rights. Never use C:\Program Files.

Android Studio is a big download, and the first setup downloads even more. Start it early.

The Standard setup installs most tools, but not the Command-line Tools. Without them flutter doctor shows "cmdline-tools component is missing". The license command asks several times: type y and press Enter each time.

Windows · Step 8

Get a phone to run your app on

Pick one. You can always add the other later.

Option A

Emulator: a virtual phone

  1. Android Studio → More Actions → Virtual Device Manager
  2. Click + → Phone → pick a Pixel → Next
  3. Download a system image → Next
  4. Additional settings → Graphics: Hardware → Finish
  5. Press ▶ to start your virtual phone
Option B · faster on weak laptops

Your own Android phone

  1. Settings → About phone → tap Build number 7 times
  2. Settings → Developer options → turn on USB debugging
  3. Connect with a data cable and tap Allow on the phone
  4. Check: flutter devices lists your phone
Chrome works as a device too, with no setup at all. It's great for a quick first test.
Emulator very slow? Turn on virtualization in your BIOS, or use your phone instead.
Mobile App Development · Lecture 02

Laptops with less than 8 GB of RAM should use their own phone: it's faster and frees memory.

Build number location varies. On Samsung it's About phone → Software information → Build number. On Xiaomi, tap "OS version" instead.

macOS

On a Mac? 3 simple steps

Real screenshot · docs.flutter.dev

  1. Download the zip for your chip: Apple Silicon (M1, M2…) or Intel
  2. Double-click the zip. Make a folder called develop in your home folder and drag flutter into it
  3. Open Terminal, paste this line, press Enter:
Terminal
$ echo 'export PATH="$HOME/develop/flutter/bin:$PATH"' >> ~/.zprofile

Then open a new Terminal and run flutter doctor. Android Studio: same steps as Windows.

Mobile App Development · Lecture 02

Check the chip: Apple menu → About This Mac. "Apple M…" means Apple Silicon (the arm64 zip). Safari may unzip the file automatically; then the flutter folder is already in Downloads.

If macOS asks to install "command line developer tools", click Install. That gives them Git. iPhone apps need Xcode, which is optional and can wait.

flutter-install-prompt.md 
You are a patient setup assistant helping a complete beginner. Goal: install Flutter for Android development on this computer.

1. Detect my OS (Windows or macOS) and CPU (x64 or ARM). Check what's already installed (git, flutter, VS Code, Android Studio) and keep what works.
2. Use official sources only: git-scm.com, docs.flutter.dev, developer.android.com, code.visualstudio.com.
3. Download the latest STABLE Flutter SDK zip from docs.flutter.dev/install/manual, extract it to C:\develop\flutter (Windows) or ~/develop/flutter (macOS), and add its bin folder to my PATH.
4. Guide me through Android Studio's SDK Manager (SDK Platform, Build-Tools, Command-line Tools, Platform-Tools, Emulator), then run: flutter doctor --android-licenses
5. Run flutter doctor -v, fix everything that blocks Android development, and run it again. Skip Visual Studio (Windows desktop apps only).
6. Prove it works: run flutter create hello_flutter, then run the app on an emulator, my phone, or Chrome.

Rules: Ask me before any admin/sudo command or system change. Explain every step in simple words. When you finish, summarize what you installed, where, and what I still need to do by hand.

Troubleshooting

Stuck? The 6 most common problems

'flutter' is not recognized… The Path line is wrong. It must be exactly C:\develop\flutter\bin. Then open a new PowerShell.
cmdline-tools component is missing Android Studio → SDK Manager → SDK Tools → tick Android SDK Command-line Tools → Apply.
Android license status unknown Run flutter doctor --android-licenses and press y for each license.
Emulator is very slow or won't start Turn on virtualization in your BIOS, close heavy apps, or use your own phone.
Strange errors, and the folder path has spaces or Arabic letters Move Flutter to C:\develop\flutter and fix the Path line to match.
Phone doesn't show up in flutter devices Use a data cable (not charge-only), tap Allow USB debugging on the phone, and try again.
Still stuck? Copy the exact error message and paste it into Google, an AI assistant, or our class group.
Mobile App Development · Lecture 02

Your first project

Create your first Flutter project

Two ways, same result. Pick the one you like.

Easiest

With VS Code

  1. Ctrl + Shift + P → Flutter: New Project
  2. Choose Application
  3. Pick a folder, e.g. Documents\flutter_projects
  4. Type a name: my_first_app → Enter
  5. Wait a moment. VS Code opens lib/main.dart

With the terminal

Naming rules

my_first_app hello_flutter2 My First App spaces, capitals my-first-app dashes 1st_app starts with a number
Mobile App Development · Lecture 02

Demo with VS Code live. The most common mistake is using spaces or capital letters in the name. Flutter will refuse it.

Rule of thumb: lowercase letters, numbers and underscores only, starting with a letter.

Your first project

What's inside your project?

Lots of folders, but you only need one for now.

├─ test/automated tests
├─ web/ windows/ …other platforms

lib/main.dart

Where your app starts. You'll spend almost all your time inside lib/.

pubspec.yaml

Your app's ID card: its name, version and the packages it uses.

android/ · ios/ · web/

Platform files Flutter manages for you. Leave them alone for now.

Your first project

Run it, then try hot reload

  1. Pick a device in the bottom-right corner of VS Code (or Flutter: Select Device)
  2. Press F5 to run. The first run takes a few minutes, and that's normal
  3. Tap the + button a few times. The counter goes up
  4. In lib/main.dart, change 'Flutter Demo Home Page' to your own title
  5. Press Ctrl + S. The title changes instantly, and the counter keeps its number
